# axonops_kafka_topic (Resource)

Manages a Kafka topic in an AxonOps-managed cluster. Topics are the fundamental unit of organization in Kafka, representing a stream of records.

## Example Usage

```terraform
# Basic topic with minimal configuration
resource "axonops_kafka_topic" "basic" {
  name               = "my-basic-topic"
  partitions         = 3
  replication_factor = 2
  cluster_name       = "my-kafka-cluster"
}

# Topic with custom configuration
resource "axonops_kafka_topic" "configured" {
  name               = "my-configured-topic"
  partitions         = 6
  replication_factor = 3
  cluster_name       = "my-kafka-cluster"

  # Topic configurations (use underscores instead of dots)
  config = {
    cleanup_policy      = "compact"
    retention_ms        = "604800000"  # 7 days
    segment_bytes       = "1073741824" # 1GB
    min_insync_replicas = "2"
  }
}
```

## In-Place Changes

- `partitions` MAY be increased in place. Decreasing `partitions` fails at `terraform plan` with `Cannot Decrease Partitions`, because Kafka does not support removing partitions from a topic.
- `replication_factor` changes are applied in place via partition reassignment. Large reassignments can take significant time and I/O on the brokers; plan reassignments during low-traffic windows.
- `name` and `cluster_name` each force replacement (`RequiresReplace`) — changing either destroys and recreates the topic, losing all data it holds.

## Schema

### Required

- `cluster_name` (String) Kafka cluster name. Changing this forces a new topic.
- `name` (String) Topic name. Changing this forces a new topic.
- `partitions` (Number) Number of partitions. Can be increased in place; decreasing is not supported by Kafka.
- `replication_factor` (Number) Replication factor. Changes are applied in place via partition reassignment.

### Optional

- `config` (Map of String) Topic configuration. Use underscores instead of dots in keys (e.g. retention_ms).

## Import

Kafka topics can be imported using the format `cluster_name/topic_name`:

```shell
terraform import axonops_kafka_topic.example my-kafka-cluster/my-topic
```

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) instead:

```terraform
import {
  to = axonops_kafka_topic.example
  id = "my-kafka-cluster/my-topic"
}
```
