# axonops_logcollector (Resource)

Manages a log collector configuration for a cluster. Log collectors define which log files to monitor, parse, and analyze for your Kafka or Cassandra cluster components.

## Example Usage

```terraform
# Kafka server log collector
resource "axonops_logcollector" "server_log" {
  cluster_name          = "my-kafka-cluster"
  name                  = "Kafka Server Log"
  filename              = "{{index . \"comp_jvm_kafka.logs.dir\"}}/server.log"
  date_format           = "yyyy-MM-dd HH:mm:ss,SSS"
  supported_agent_types = ["broker", "kraft-broker"]
}

# Kafka controller log collector
resource "axonops_logcollector" "controller_log" {
  cluster_name          = "my-kafka-cluster"
  name                  = "Kafka Controller Log"

  date_format           = "yyyy-MM-dd HH:mm:ss,SSS"
  supported_agent_types = ["kraft-controller"]
}
```

## Schema

### Required

- `cluster_name` (String) The name of the Kafka cluster.
- `filename` (String) The log file path. Supports Go templating (e.g., {{index . "comp_jvm_kafka.logs.dir"}}/server.log).
- `name` (String) The name of the log collector.

### Optional

- `date_format` (String) The date format used in log entries. Default: yyyy-MM-dd HH:mm:ss,SSS
- `debug_regex` (String) Regex pattern for DEBUG level log entries.
- `error_alert_threshold` (Number) Threshold for error alerts. Default: 0
- `error_regex` (String) Regex pattern for ERROR level log entries.
- `info_regex` (String) Regex pattern for INFO level log entries.
- `supported_agent_types` (List of String) List of agent types this collector supports (e.g., all, broker, kraft-broker, kraft-controller, zookeeper, schema-registry).
- `warning_regex` (String) Regex pattern for WARNING level log entries.

### Read-Only

- `uuid` (String) The unique identifier for the log collector (auto-generated).

## Import

Log collectors can be imported using the format `cluster_name/logcollector_name`:

```shell
terraform import axonops_logcollector.example my-kafka-cluster/Kafka%20Server%20Log
```

Where:
- `cluster_name` - The name of the cluster
- `logcollector_name` - The name of the log collector (URL-encoded if it contains spaces)
