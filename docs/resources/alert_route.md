# axonops_alert_route (Resource)

Manages an alert route to an integration (e.g., Slack, PagerDuty, email).

Alert routes allow you to send alerts from AxonOps to external integrations such as:
- **Slack** - Send alerts to Slack channels
- **PagerDuty** - Integrate with PagerDuty for incident management
- **Email** - Send alert notifications via email
- **Microsoft Teams** - Post alerts to Teams channels
- **ServiceNow** - Create incidents in ServiceNow
- **Webhook** - Send alerts to custom webhook endpoints
- **OpsGenie** - Integrate with OpsGenie for alerting

## Route Types

The `type` attribute determines which alerts are routed:
- `global` - All alerts
- `metrics` - Metric-based alerts
- `backups` - Backup-related alerts
- `servicechecks` - Service check alerts (health checks)
- `nodes` - Node status alerts
- `commands` - Command execution alerts
- `repairs` - Repair operation alerts
- `rollingrestart` - Rolling restart alerts

## Example Usage

```terraform
# Global route - send all error alerts to PagerDuty
resource "axonops_alert_route" "global_pagerduty" {
  cluster_name     = "my-kafka-cluster"
  cluster_type     = "kafka"
  integration_name = "ops-pagerduty"
  integration_type = "pagerduty"
  type             = "global"
  severity         = "error"
}

# Category-specific route - send metric warnings to Slack with override
resource "axonops_alert_route" "metrics_slack" {
  cluster_name     = "my-cassandra-cluster"
  cluster_type     = "cassandra"
  integration_name = "metrics-slack"
  integration_type = "slack"
  type             = "metrics"
  severity         = "warning"
}

# Route without override
resource "axonops_alert_route" "nodes_webhook" {
  cluster_name     = "my-cassandra-cluster"
  cluster_type     = "cassandra"
  integration_name = "monitoring-webhook"
  integration_type = "webhook"
  type             = "nodes"
  severity         = "info"
  enable_override  = false
}
```

## Schema

### Required

- `cluster_name` (String) The name of the cluster.
- `cluster_type` (String) The cluster type (cassandra, kafka, or dse).
- `integration_name` (String) The name of the integration.
- `integration_type` (String) The type of integration: email, smtp, pagerduty, slack, teams, servicenow, webhook, opsgenie.
- `severity` (String) The severity level: info, warning, error.
- `type` (String) The route type: global, metrics, backups, servicechecks, nodes, commands, repairs, rollingrestart.

### Optional

- `enable_override` (Boolean) Enable override for non-global routes. Ignored for global routes. Default: true

### Read-Only

- `id` (String) Composite identifier: cluster_type/cluster_name/type/severity/integration_type/integration_name.

## Import

Alert routes can be imported using the format `cluster_type/cluster_name/type/severity/integration_type/integration_name`:

```shell
terraform import axonops_alert_route.example cassandra/my-cassandra-cluster/metrics/warning/slack/metrics-slack
```

Where:
- `cluster_type` - The type of cluster (cassandra, kafka, or dse)
- `cluster_name` - The name of the cluster
- `type` - The route type (global, metrics, backups, servicechecks, nodes, commands, repairs, rollingrestart)
- `severity` - The severity this route applies to (info, warning, error); ignored when `type` is `global`, but a value MUST still be supplied
- `integration_type` - The integration type (email, smtp, pagerduty, slack, teams, servicenow, webhook, opsgenie)
- `integration_name` - The name of the integration (the `name` attribute of the corresponding integration resource, not its ID)

> **Warning:** The import ID has 6 slash-separated parts, in this exact order. An import ID with 4 parts (e.g. `cassandra/my-cluster/slack/metrics`) fails with `Invalid Import ID`.

## Replacement Behaviour

`cluster_name`, `cluster_type`, `type`, `severity`, `integration_type`, and `integration_name` each force replacement (`RequiresReplace`) — they form the route's identity, and AxonOps has no API to change a route's identity in place. Changing any of them destroys the existing route and creates a new one. Only `enable_override` can be updated in place.
