# axonops_schema (Resource)

Manages a Schema Registry schema subject. Schema Registry provides a centralized repository for managing and validating schemas for Kafka message data, supporting AVRO, JSON Schema, and Protobuf formats.

## Example Usage

```terraform
# Simple Avro schema for user events
resource "axonops_schema" "user_events" {
  cluster_name = "my-kafka-cluster"
  subject      = "user-events-value"
  schema_type  = "AVRO"
  schema       = jsonencode({
    type      = "record"
    name      = "UserEvent"
    namespace = "com.example.events"
    fields    = [
      {
        name = "user_id"
        type = "string"
      },
      {
        name = "event_type"
        type = "string"
      },
      {
        name = "timestamp"
        type = "long"
      },
      {
        name    = "metadata"
        type    = ["null", "string"]
        default = null
      }
    ]
  })
}

# JSON Schema example
resource "axonops_schema" "notifications" {
  cluster_name = "my-kafka-cluster"
  subject      = "notifications-value"
  schema_type  = "JSON"
  schema       = jsonencode({
    "$schema"    = "http://json-schema.org/draft-07/schema#"
    type         = "object"
    title        = "Notification"
    required     = ["id", "type", "message", "timestamp"]
    properties   = {
      id = {
        type = "string"
        format = "uuid"
      }
      type = {
        type = "string"
        enum = ["email", "sms", "push"]
      }
      recipient = {
        type = "string"
      }
      message = {
        type = "string"
        maxLength = 1000
      }
      timestamp = {
        type = "integer"
      }
      metadata = {
        type = "object"
        additionalProperties = true
      }
    }
  })
}
```

## Schema

### Required

- `cluster_name` (String) The name of the Kafka cluster.
- `schema` (String) The schema definition (JSON string for AVRO/JSON, proto definition for PROTOBUF).
- `schema_type` (String) The schema type. Valid values: AVRO, PROTOBUF, JSON.
- `subject` (String) The subject name (e.g., topic-name-value or topic-name-key).

### Read-Only

- `schema_id` (Number) The unique ID assigned to the schema by the Schema Registry.
- `version` (Number) The version number of the schema.

## Import

Schema Registry schemas can be imported using the format `cluster_name/subject`:

```shell
terraform import axonops_schema.example my-kafka-cluster/user-events-value
```

Where:
- `cluster_name` - The name of the Kafka cluster
- `subject` - The subject name (e.g., topic-name-value or topic-name-key)
