# axonops_cassandra_adaptive_repair (Data Source)

Reads Cassandra adaptive repair settings for a cluster. Use this data source to retrieve the current adaptive repair configuration, including parallelism, thresholds, and excluded tables.

## Example Usage

```terraform
# Read existing adaptive repair settings
data "axonops_cassandra_adaptive_repair" "existing" {
  cluster_name = "my-cassandra-cluster"
}

# Output repair settings
output "repair_active" {
  value = data.axonops_cassandra_adaptive_repair.existing.active
}

output "repair_parallelism" {
  value = data.axonops_cassandra_adaptive_repair.existing.parallelism
}

output "gc_grace_threshold" {
  value = data.axonops_cassandra_adaptive_repair.existing.gc_grace_threshold
}

output "blacklisted_tables" {
  value = data.axonops_cassandra_adaptive_repair.existing.blacklisted_tables
}

# Read DSE cluster adaptive repair settings
data "axonops_cassandra_adaptive_repair" "dse" {
  cluster_name = "my-dse-cluster"
  cluster_type = "dse"
}
```

## Schema

### Required

- `cluster_name` (String) The name of the cluster.

### Optional

- `cluster_type` (String) The cluster type (cassandra or dse). Default: cassandra

### Read-Only

- `active` (Boolean) Whether adaptive repair is enabled.
- `blacklisted_tables` (List of String) List of tables excluded from repair.
- `filter_twcs_tables` (Boolean) Whether TWCS tables are excluded.
- `gc_grace_threshold` (Number) GC grace period threshold in seconds.
- `parallelism` (Number) Number of tables to repair concurrently.
- `segment_retries` (Number) Maximum retry attempts per segment.
- `segment_target_size_mb` (Number) Target segment size in MB.
- `segments_per_vnode` (Number) Number of segments per vnode.
