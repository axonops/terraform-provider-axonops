# axonops_clusters (Data Source)

Lists the clusters in the organisation that the API key can access.

Use this data source to drive `for_each` over every cluster in the organisation, for example to apply the same alert rules or integrations to all Cassandra clusters. Only clusters the API key can access are returned. Status is the cluster alert level: `green` (no alerts), `amber` (warnings) or `red` (errors).

## Example Usage

```terraform
# List every cluster in the organisation
data "axonops_clusters" "all" {}

output "all_clusters" {
  value = data.axonops_clusters.all.clusters
}

# Only Cassandra clusters
data "axonops_clusters" "cassandra" {
  type = "cassandra"
}

# Clusters currently raising error-level alerts
output "red_clusters" {
  value = [for c in data.axonops_clusters.all.clusters : c.id if c.status == "red"]
}

# Apply the same Slack integration to every Cassandra cluster
resource "axonops_slack_integration" "ops" {
  for_each = toset(data.axonops_clusters.cassandra.names)

  cluster_name = each.value
  cluster_type = "cassandra"
  name         = "ops-alerts"
  webhook_url  = var.slack_webhook_url
  channel      = "#ops-alerts"
}

variable "slack_webhook_url" {
  type      = string
  sensitive = true
}
```
