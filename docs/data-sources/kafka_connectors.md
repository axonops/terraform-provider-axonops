# axonops_kafka_connectors (Data Source)

Lists the connectors in a Kafka Connect cluster attached to a Kafka cluster.

Use this data source to discover the connectors running in a Kafka Connect cluster, optionally filtered by `type`, for monitoring or dependency wiring.

## Example Usage

```terraform
# List every connector in a Kafka Connect cluster
data "axonops_kafka_connectors" "all" {
  cluster_name         = "my-kafka-cluster"
  connect_cluster_name = "my-connect-cluster"
}

# Only sink connectors
data "axonops_kafka_connectors" "sinks" {
  cluster_name         = "my-kafka-cluster"
  connect_cluster_name = "my-connect-cluster"
  type                 = "sink"
}

output "sink_connector_names" {
  value = data.axonops_kafka_connectors.sinks.names
}

# Connectors that are not running
output "unhealthy_connectors" {
  value = [
    for c in data.axonops_kafka_connectors.all.connectors : c.name
    if c.state != "RUNNING"
  ]
}
```

## Schema

### Required

- `cluster_name` (String) The name of the Kafka cluster.
- `connect_cluster_name` (String) The name of the Kafka Connect cluster.

### Optional

- `type` (String) Only return connectors of this type. Valid values: `source`, `sink`.

### Read-Only

- `connectors` (Attributes List) Matching connectors, sorted by name. (see [below for nested schema](#nestedatt--connectors))
- `names` (List of String) Sorted list of matching connector names.
