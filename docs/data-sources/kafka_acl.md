# axonops_kafka_acl (Data Source)

Looks up a single Kafka ACL entry matching the given identity fields. Errors if no matching ACL is found.

~> **Note:** This data source returns a single ACL entry and errors if no matching ACL is found. To list all ACLs matching partial criteria, use the [`axonops_kafka_acl_list`](kafka_acl_list.md) data source instead.

## Example Usage

```terraform
data "axonops_kafka_acl" "producer" {
  cluster_name          = "my-kafka-cluster"
  resource_type         = "TOPIC"
  resource_name         = "my-topic"
  resource_pattern_type = "LITERAL"
  principal             = "User:producer-app"
  host                  = "*"
  operation             = "WRITE"
  permission_type       = "ALLOW"
}
```
