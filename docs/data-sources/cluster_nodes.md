# axonops_cluster_nodes (Data Source)

Lists the nodes (agents) registered in a cluster.

Use this data source to list the nodes (AxonOps agents) of a cluster, for example to find nodes that are down or to scope resources to one data centre. A node is `up` when its agent is connected to AxonOps.

## Example Usage

```terraform
# List every node in a cluster
data "axonops_cluster_nodes" "all" {
  cluster_name = "prod-cassandra"
  cluster_type = "cassandra"
}

output "node_ips" {
  value = [for n in data.axonops_cluster_nodes.all.nodes : n.host_ip]
}

# Only nodes whose agent is disconnected
data "axonops_cluster_nodes" "down" {
  cluster_name = "prod-cassandra"
  cluster_type = "cassandra"
  status       = "down"
}

output "down_nodes" {
  value = [for n in data.axonops_cluster_nodes.down.nodes : "${n.hostname} (${n.datacenter}/${n.rack})"]
}

# Only nodes in one data centre
data "axonops_cluster_nodes" "eu" {
  cluster_name = "prod-cassandra"
  cluster_type = "cassandra"
  datacenter   = "eu-west-1"
}

output "eu_host_ids" {
  value = data.axonops_cluster_nodes.eu.host_ids
}
```

## Schema

### Required

- `cluster_name` (String) The name of the cluster.
- `cluster_type` (String) The cluster type (cassandra, kafka, or dse).

### Optional

- `datacenter` (String) Only return nodes in this data centre.
- `status` (String) Only return nodes with this agent status. Valid values: `up`, `down`.

### Read-Only

- `host_ids` (List of String) Host IDs of the matching nodes, in the same order as `nodes`.
- `nodes` (Attributes List) Matching nodes, sorted by data centre, rack, then host IP. (see [below for nested schema](#nestedatt--nodes))

### Nested Schema for `nodes`

Read-Only:

- `agent_version` (String) The AxonOps agent version.
- `datacenter` (String) The data centre of the node.
- `host_id` (String) The AxonOps host ID of the node.
- `host_ip` (String) The node IP address.
- `hostname` (String) The human-readable node identifier (usually the hostname).
- `node_type` (String) The node role reported by the agent (for example a Kafka broker or KRaft controller). Empty when not reported.
- `rack` (String) The rack of the node.
- `status` (String) The agent status: `up` when connected, otherwise `down`.
- `version` (String) The Cassandra/Kafka version running on the node.
