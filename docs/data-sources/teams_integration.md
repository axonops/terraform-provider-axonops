# axonops_teams_integration (Data Source)

Reads an existing Microsoft Teams integration from AxonOps. Use this data source to reference integration details when configuring `axonops_alert_route` resources that target an integration managed outside of the current Terraform root module.

## Example Usage

```terraform
data "axonops_teams_integration" "existing" {
  cluster_name = "production-cassandra"
  cluster_type = "cassandra"
  name         = "ops-teams-alerts"
}

output "teams_integration_id" {
  value = data.axonops_teams_integration.existing.id
}
```
