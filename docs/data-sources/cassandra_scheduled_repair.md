# axonops_cassandra_scheduled_repair (Data Source)

Reads a Cassandra scheduled repair configuration by tag.

## Example Usage

```terraform
# Read an existing scheduled repair by tag
data "axonops_cassandra_scheduled_repair" "existing" {
  cluster_name = "my-cassandra-cluster"
  tag          = "monthly-full-repair"
}

output "repair_schedule" {
  value = data.axonops_cassandra_scheduled_repair.existing.schedule_expr
}

output "repair_parallelism" {
  value = data.axonops_cassandra_scheduled_repair.existing.parallelism
}
```
